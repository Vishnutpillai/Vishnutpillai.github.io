# Vishnu T Pillai | Portfolio

Personal portfolio of **Vishnu T Pillai**, MLOps Engineer and Data Scientist based in Ernakulam, Kerala, India.

**Live site:** https://vishnutpillai.github.io

## About

A single-page portfolio that presents my work in data science, machine learning, MLOps and AI. It covers my projects, skills, experience and how to reach me.

## Features

- Interactive k-means clustering demo in the hero (click to add data points)
- Light and dark theme toggle that remembers your choice
- Project cards with clickable pipeline diagrams that explain how each project works
- Filter projects by area: Machine learning, AI & RAG, Analytics, MLOps
- Tabbed skills, experience timeline and downloadable resume
- Responsive layout, keyboard-friendly focus styles and reduced-motion support

## Run locally

No install is needed.

1. Clone or download this repository.
2. Open `index.html` in your browser.

Optionally, serve it locally:

```bash
python -m http.server 8000
```

Then visit http://localhost:8000.

## Deploy

This site is hosted on GitHub Pages:

1. Push these files to a repository named `Vishnutpillai.github.io`.
2. Go to **Settings → Pages**, choose the `main` branch and `/ (root)`, then save.
3. The site goes live at https://vishnutpillai.github.io within a couple of minutes.
